### Deep Convolutional GAN (DCGAN) for Realistic Human Face Synthesis

**25 Mar, 2026 - 31 Mar, 2026**\
**Mentor:** Dr. Neena Raj N R\
**Team Size:** 4\
**Project Link:**
https://github.com/ajsike2310/Deep-Convolutional-Generative-Adversarial-Network-DCGAN-for-Realistic-Human-Face-Synthesis

This project involved building a Deep Convolutional GAN using Python and
PyTorch to generate realistic human faces from scratch, without using
any real photographs as direct output. The model works by training a
Generator and Discriminator network against each other using transposed
convolutions and batch normalization, where one creates faces and the
other judges how convincing they look, pushing both to improve over time
through adversarial training. Trained on large scale human face datasets
and GPU accelerated through PyTorch, the system progressively produces
higher quality results across training epochs by sampling from a latent
space. The project explores the creative and technical potential of
generative AI and deep learning in the domain of synthetic image
creation.

### Vigil Eye - Drowsiness Detection System

**01 Nov, 2024 - 15 Nov, 2024**\
**Team Size:** 2\
**Project Link:** https://github.com/ajsike2310/Vigil-Eye

Vigil Eye is a real-time drowsiness detection system built with Python,
OpenCV, and dlib, designed to improve driver safety by monitoring eye
activity through a live webcam feed. The system continuously analyzes
facial landmarks using dlib's 68-point shape predictor model to track
Eye Aspect Ratio, detecting prolonged eye closure as a fatigue indicator
and triggering a pygame powered audio alert when drowsiness is detected.
Using computer vision and scipy based distance calculations, it
precisely locates and measures eye regions frame by frame, making
detection both accurate and responsive. The experience is wrapped in a
simple Tkinter interface that lets users start and stop monitoring with
ease, demonstrating a practical and potentially life saving application
of deep learning and computer vision in everyday safety scenarios.
